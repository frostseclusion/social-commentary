## 关于这个仓

- **结构**：`posts/` 是唯一会被发布的内容；`drafts/` 只在本地，不进仓库。
- **发布**：写完从 `drafts/` 挪进 `posts/`，把 `status` 改成 `published`，提交即可，目录自动重排。
- **许可**：正文按 [CC BY-NC-SA 4.0](LICENSE) 授权（署名 / 非商业 / 改编后须同样开放）；`scripts/` 用 [MIT](scripts/LICENSE)。
